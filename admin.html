Cómo funciona: este panel no necesita PHP ni base de datos. Los cambios se guardan temporalmente en este navegador. Cuando termines, pulsa Descargar data.js y reemplaza js/data.js en GitHub. Las imágenes deben estar dentro de la carpeta img/.

      🚀 Publicar cambios

      Cuando termines de editar, descarga el archivo y súbelo a GitHub:

      1. Pulsa Descargar data.js.
      2. En GitHub abre js/data.js.
      3. Reemplaza su contenido con el archivo descargado.
      4. Si agregaste imágenes nuevas, súbelas a img/.
      5. Espera unos minutos y abre tu GitHub Page.
